# Android Native V2 — 1.238 점검 반영

- 기준: `android-native-v2` cc80e73 + main 0b8ad6e (1.238 TabSwipe/가이드 포함).
- 대상: Android Kotlin. `src/App.tsx`, `openAndroidNativeV2` 임시 다리는 그대로 유지.
- main 병합은 하지 않음. Claude가 웹 부트스트랩을 맞춘 뒤 통합할 것.

## 통합 전 확인할 것

- 알림함→라운드→뒤로=알림함, 대화→카드→뒤로=대화(스크롤/초안 유지).
- 키보드 열린 상태와 취소한 손짓, 반복 진입, 탭 누르기/끌기 구분.
- 다른 앱을 보고 있으면 대화 알림도 표시, 대화 중에는 정산/조 편성 배너 표시.
- 코틀린만 수정한 항목도 실기기 움직임은 자동 단위 검사와 별도로 확인한다.
