# 수리노트 운영 안내

## 계정과 회원 승인

앱은 현재 teetime 저장소의 Supabase 인증과 회원 프로필을 사용합니다. 새 엔지니어가 카카오 또는 Apple로 로그인하면 기존 승인 화면에 대기 회원으로 표시되고, 운영자 권한(`staff`, `admin`, `superadmin`)을 가진 회원이 승인한 뒤 자료를 이용할 수 있습니다.

OAuth 제공자 설정의 허용 주소에는 다음 페이지 주소를 등록해야 합니다.

- `https://seongho1203-star.github.io/teetime/`

## 데이터베이스 적용

`supabase/repair_knowledge.sql`은 별도 `repair_entries` 테이블과 `repair-photos` 비공개 저장소를 추가합니다. 기존 골프용 테이블과 글·사진은 수정하거나 옮기지 않습니다. 적용하면 승인 회원만 지식 글과 사진을 읽을 수 있고, 작성자와 운영자만 글을 삭제할 수 있습니다.

배포 Actions에 `SUPABASE_DB_URL`이 설정돼 있으면 수리 지식 SQL을 자동 적용합니다. 설정이 없으면 Supabase Dashboard의 SQL Editor에서 파일 전체를 실행해 주세요. 파일은 여러 번 실행해도 안전하도록 작성했습니다.

## 알림

새 지식 등록 시 모든 승인 회원의 앱 알림함에 알림이 저장됩니다. 앱이 닫힌 상태에서 받는 푸시 알림은 회원이 각 기기에서 알림을 켠 경우 발송됩니다. 푸시는 기존 `notify` Edge Function과 구독을 재사용합니다.

## 자료 등록 시 유의 사항

- 모델명을 제품 라벨과 대조하고, 재현 조건과 측정값을 구체적으로 기록합니다.
- 테스트 모드와 히든 키는 모델·절차를 확인하고 현장 안전 기준에 따라 사용합니다.
- 고객 이름, 주소, 연락처, 집 내부 등 개인정보나 고객 식별 정보가 담긴 사진은 올리지 않습니다.
- 검증 표시는 운영자가 확인한 자료에만 설정합니다.
